# 引用图解

用一张或一组图讲清作者的观点、依据和读者可以尝试的动作。用户可以直接使用无角色版式，也可以附上有权使用的插画或个人角色素材。

1. 读取用户提供的正文或 Markdown 剪藏。链接能读到正文时也可以使用。先分清作者观点、你的解读和示例，在成品保留作者与出处。若链接缺正文，提示补需要的段落或剪藏。
2. 每页回答一个问题。短帖先做一张。长文按论证或做法拆页，组图默认等高。用左右对照解释差异，用箭头表达真实顺序，用表格或清单交付具体判断和动作。
3. 用[版式与运行方式](references/layout.md)生成 UTF-8 页面 JSON。默认省略 `art`，排版会使用整个标题区域。使用插画时，正文、图表标签、箭头和来源由排版脚本写入，图像工具负责无字素材。
4. 运行 `scripts/render.py`，用 `--preview` 打开 390 像素宽的预览，检查中文、断行、遮挡、结构和署名，再交付可打开的 PNG。没有 Python、Pillow 或指定字体时，交付可编辑页面 JSON 和来源，说明缺少的运行条件。

第一次可以直接渲染[原创建例](examples/handoff.json)，原文见[示例正文](examples/handoff-source.md)。
