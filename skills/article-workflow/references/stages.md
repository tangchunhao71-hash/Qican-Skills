# 通用文章工作流

| 阶段 | 输入与操作 | 交付与继续条件 |
| --- | --- | --- |
| 选题开发 | 真实材料、判断、目标读者；评价是否存在现实问题、独到视角、可支撑论证和可兑现价值 | 候选方案与选择理由；作者确认标题、主旨和主要结构 |
| 正式选题卡 | 已确认方向、研究逻辑、材料来源、反例、章节职责、实践设计、公开边界 | 正式卡全文；存储获准时查重、保存、独立读回；给写作交接 |
| 写作生产 | 读取完整选题卡、当前正式规则及必要原始资料；由实际写作入口自主研究，理解作者的发现与分享动机，在分享者和阅读者视角间切换，自然表达 | 真实稿件；记录资料读取、实际模型/入口和版本（可观察范围） |
| 实质审阅 | 核心论点、论证、事实、引用、实际可兑现价值及实践验证 | 无实质问题即采用；有则定位理由、交原写作者修订。尊重作者已确认方向 |
| 初稿交付 | 核对已采用正文、原生结构、出处和可编辑性；按需注明配图用途和位置 | 交可编辑文字稿，等待作者精修 |
| 精修接续 | 作者明确确认完成，读当前实际全文与版本；核对变化和素材 | 保护作者正文，按需排版并检查链接；交待发布文字稿 |
| 复盘 | 已发布作品、可得实际反馈及初稿/精修差异 | 区分写作质量对照与真实价值反馈；缺失为未知；规则与知识更新由作者决定 |

## 四部分选题卡
1. 标题与一句话主旨：目标读者、现实问题、价值承诺、必要取舍和边界。避免标题依赖读者不了解的术语。
2. 整体行文脉络：读者如何从熟悉问题走向理解、判断及行动。
3. 章节设计：章节、行文逻辑、真实衔接、实践方向（按需）；保留核心论证、知识依据、反例、案例、类比、转译和必要视觉职责。章数与篇幅服从实际价值。
4. 已有材料与缺口：可回查来源、证据强度、待核实及公开边界。按篇补充实质审阅重点与发布后拟验证的问题，不新增固定表单。

## 交付验收
核对文章身份、实际版本、来源、正文完整性以及与批准方向的关系。若涉及平台写入，应保留实际保存证据及独立读回；无结构核验能力就不报告完整交付。保护人工修改，不同稿件不混合，保存失败或状态未知先查重再考虑重试。对实操内容按实际结果验收，提示词或预期结果不替代运行。视觉素材要有来源与授权，真实截图按需脱敏，示意图标明用途。
