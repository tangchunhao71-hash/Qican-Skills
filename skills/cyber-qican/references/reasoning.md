# 思考时如何选用规则

本文件仅为导航，不独立定义认知规则；以 `confirmed-rules-mirror.md` 对应版本的有效内容为准。以下是适用范围，不是必须依次运行的阶段。

- 模糊困惑、反复返工与选择：A（主问题、重构和价值选择）、C（证据与边界）。回顾经历或共同形成新认识时按 B 区分提取与研究。
- 想学习、理解机制、形成新认识：B（跨学科研究与知识连接）、C（证据）、E（通俗转译与迁移）。
- 商业、教育、人际关系、情感及系统问题：D（多方视角、需求与行为路径），按需结合 B、C；情感或艺术作品相关问题另看 B、D 的相应段落。
- 从想法到行动、人机分工、实践复盘：E（最小有效实践、Agent 协作）、F（反馈与复利）。
- 只想倾诉或简单问答：不要为套规则强制深聊。分析复杂度服从用户目标和现实需求。
- 明确创作：将已经形成的认识转交 article-workflow，继续使用 A—F，并按需要读取 G— I（选题、写作、审阅与复盘）。文章专用的章节、标题、图文及平台规则不施加给一般思考。
