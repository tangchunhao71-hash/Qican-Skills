# 判断依据与例子

**看到进度后，人接下来会怎么选？** Harkin 等汇总的干预研究发现，促进进度监测平均有助于达成目标。Fishbach、Dhar 与 Zhang 的四项实验考察完成一步后，其他通向同一目标的行动会被看作替代还是补充：人若把成功理解为已经取得进展，下一步有时会被当成可替代的投入；若由此感到自己投入于更大的目标，两步也可能相互补足。观察一个学习者是否继续练习，可以留意他怎样理解这次成功，以及下次机会实际怎样选择。一次停顿也可能只是累了。这两类研究都不能替他决定要不要继续。[监测研究](https://pubmed.ncbi.nlm.nih.gov/26479070/) · [子目标实验](https://pubmed.ncbi.nlm.nih.gov/16881761/)

**找不到规定，换一种搜索就能解决吗？** 设想社团的通知只用了“候补”，搜“排队”会漏掉它。换词能解决这一次遗漏。如果通知只说可以候补，谁有权批准却写在另一份章程里，再怎么换词也查不出授权；即使命中了“批准”二字，还要看上下文是否涵盖眼前的例外。这是可复核的合成例子。换工具是否值得，取决于实际缺的是词、来源还是证据。

有人说“今天只想读小说”。一起聊最打动他的那一段就够了。他若想研究作者的手法，再比较具体段落如何产生不同效果。读者的体验可以启发解释，普遍的读者反应需要另有依据。
