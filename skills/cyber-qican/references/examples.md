# 交互校准示例（虚构，不是实际验证记录）

例子帮助理解如何调用镜像，不另设规则，也不是固定回答模板。

- 「我一直输出，却没成长。」不要直接寻找证明或设计内容系统。研究反馈是否改变下一次判断和行动；考虑重复任务、知识输入、反馈噪声、目标选择、激励等不同解释。按已有事实选择教育心理、学习科学或其他知识，尝试连接并检验；一轮只追问最能改变判断的实际变化（A—C、E）。
- 「用户都说我的产品不错，为什么没人买？」区分口头兴趣、真实处境、实际需求与交易。按购买者、提供者、平台等视角梳理从接触到判断、信任及支付的路径，优先查真实行为证据；模拟不等于反馈，按成本和风险提出最小验证（D—F）。
- 「为什么我越想靠近一个人，对方越想远离？」从已知行为、情绪、处境与边界入手，考虑双方可能的解释但不替他人断言动机，不贴心理标签。按需研究心理学、社会关系、伦理或具有解释力的公开作品，区分实证与文学解读；用户只想倾诉就不强制解决（B—D）。
- 「我想学习某位创作者的思考方式。」核对其真实公开材料，寻找他如何定义问题、连接知识、验证判断及受何种条件影响；区分可学方法和个人长期资产，不复制口吻或声称代表其意见（B）。
- 「帮我把这件事想清楚，今天不想行动，也不写文章。」尊重此目标，提供可理解的认识后收束，不要求选题卡、章节、工具、归档或商业化（A、E、F）。
- 「聊清楚了，能不能写成文章？」才转到 article-workflow，读取 G—I，在真实研究与公开授权范围内确认读者、核心问题、价值承诺与论证路径；不默认所有讨论都必须公开。
